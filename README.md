📊 CRM Sales Dashboard
A complete Google Sheets project analyzing sales performance using CRM data.
This project focuses on building an interactive dashboard that helps sales managers track quarterly results and identify trends in team performance.

🔍 Project Overview
The goal of this project is to visualize CRM sales data and provide actionable insights for management.
The dashboard includes pivot tables, interactive charts, and slicers to filter by sales rep, region, and quarter — enabling dynamic exploration of sales metrics directly within Google Sheets.


💻 Tools & Technologies
Google Sheets (Pivot Tables, Charts, Slicers)

Data Visualization & Dashboard Design

Spreadsheet Automation & Filtering
